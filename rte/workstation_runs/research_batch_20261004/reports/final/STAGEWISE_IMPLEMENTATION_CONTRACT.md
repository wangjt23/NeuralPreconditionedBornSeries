# Stagewise Euclidean residual checker

This newly authored module certifies the exact nominal discrete operator with the captured original pure-imaginary complex128 streaming symbol and the exact binary material, phase, weight, source and candidate values supplied by its executor. It makes no GPU-wide error claim. Prior authored dependencies are copied byte for byte and sealed in `DEPENDENCY_SEALS.json`; original project sources and arrays are absent.

`stagewise_fft.py` exposes `StagewiseBall(center, radius_upper)`, `fft_ball`, `fft2_ball`, `physical_action_ball`, `ball_norm_bounds`, `paired_field_check`, and `certify_residual`. The last API accepts the prior operator arguments and optional `baseline=...`. Its scalar output contains directed bounds, exact rational acceptance predicates, per-stage radius/cost receipts and total helper costs; no arrays are returned. The factor/solver is never invoked by this checker.

For a represented center c and an incoming Euclidean radius E, each bit-reversed radix2 layer constructs an interval enclosure of the exact layer applied to c. It selects a new represented center d inside the local box and bounds the vector error by `e=norm_upper(local_box-point(d))`. Prior uncertainty propagates as `E_next <= sqrt(2)*E+e`; the stored sqrt(2) constant and scalar multiplication/addition are rounded outward with exact Fractions. Permutations preserve the Euclidean norm. Each inverse axis scales by exact `1/N`, with any rounding/underflow of its represented center enclosed separately. Thus the two-dimensional forward operator norm is `sqrt(Nx*Ny)` and the normalized inverse norm is its reciprocal.

For the stored pure-imaginary D64 diagonal, exact sign/swap followed by real native multiplication encloses the local center action. The prior radius is multiplied by the exact maximum absolute stored imaginary coefficient. Collision/scattering acts on the exact original candidate, with weights multiplied before phase mixing and every product and angular sum enclosed locally; no rounded point phase-weight matrix replaces it. Collision, final streaming-plus-collision addition and source subtraction contribute local radii by the triangle inequality. The final residual norm enclosure is `max(0,C_L-E_U)` through `C_U+E_U`.

Only exact endpoint equality enables zero, one, minus-one or cardinal-root shortcuts. Zero addition/cancellation and multiplication by 0 or ±1, and rotations by ±i, are exact real binary sign/index operations. Their outputs own storage. General roots, nonzero additions and power-of-two scaling still use outward native interval operations; underflow is never discarded by a tolerance test. The copied native guard remains read-only, requires binary64 nearest rounding with FTZ/DAZ disabled, and rejects nonfinite results. The compiler/IEEE/nextafter contract remains an explicit trust base; finite fixtures do not prove all CPU arithmetic.

The prospective residual gate is unchanged: exact tau=1/100000 and alpha=1/100 require `C_U <= (1-alpha)*tau*Q_L`, `E_U <= alpha*tau*Q_L`, and `R_U <= tau*Q_L`. The relative solution-error gate requires a positive denominator and `R_U/(m*X_L-R_U) <= 1/1000`, using the exact independently derived coefficient margin m. A nonpositive source norm or solution denominator fails closed without a fabricated solution bound.

With a supplied represented baseline, the separate paired-field predicate is `difference_norm_U <= (1/10000)*baseline_norm_L`, with positive baseline denominator. The difference is enclosed directly from the exact input bits, including subtraction and norm arithmetic. A rigorous negative certificate additionally requires `difference_norm_L > (1/10000)*baseline_norm_U`; an upper-bound failure alone is inconclusive. Absent baseline, scalar accuracy acceptance does not establish paired-field acceptance or admit a full solver comparison.

Each FFT stage records its incoming radius, local error, outgoing radius, interval-action time and recenter/local-norm time. Inverse scaling, D multiplication, collision and final action addition retain their own cost receipts. The certificate separately times initial/final CPU guards, exact coefficient margin, source/candidate norms, full action, residual center/radius, residual norm, paired-field check and exact acceptance. These timers are nested within total helper elapsed time and must not be added twice. The consuming executor must additionally report setup, compilation, transfers, buffer hashes, persistence and whole verification wall cost.

Local verification uses only tiny fixtures of at most 16 spatial points per axis, exact Fraction DFT oracles and the existing system compiler. FWI preflight and independent scientific/source reviews must precede any authorized full-grid verification; no full-grid Mac run, GPU action, training, held-out source or solver comparison is authorized by this implementation deliverable.
