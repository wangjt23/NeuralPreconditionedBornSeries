# RTE 层状背景实验结论

## 决策

保留原生 TSA16/seg 为当前单右端项基线，不训练“局部散射源 q”网络，不把本原型升为默认求解器。

本轮得到一个正结果和两个否决结果：

1. 层状结构确实提供了均匀背景和 TSA1 所没有的有效方向。全 16 个复用开发样本，N256 的热求解成本降低 8.64%；N128 降低 3.00%，其配对重采样区间跨零。
2. 当前层状因子的初始化成本使单右端项总成本分别增加 46.52% 和 84.20%。它是一个尚未经济化的方向生成器，不是更快的完整求解器。
3. “免费准确物理散射源”未能胜过直接层状 G。原因不仅是预测困难，而是近似背景算子与原 Fourier 离散不一致。先训练网络无法解决这个定义错误。

所有结论只针对本轮固定实现、数据与工作负载。没有排除所有层状求解器、所有学习目标或多右端项应用。

## 对象和不变条件

原问题 A u = b 使用仓库原始 PeriodicRTE2D Fourier 离散、12 个角度、g=0.65、epsilon=0.1。数据来自既有开发库，16 个介质，N128 与 N256。材料为平移/旋转的层状背景加 inclusion。未使用预留 9626，未训练、未生成新精确解。

A_s 是从实际材料提取的一维背景所对应的**原 Fourier 离散**；V=A-A_s。代码从两个坐标方向分别取横向最小 sigma_t，并在同一 argmin 取 sigma_s，以较小的材料差平方和选择层法向。保留完整 V，不截断 inclusion。

实现的 G_tilde 不是 A_s 的精确逆。它在切向使用 Fourier，在法向使用 compact4 或一阶迎风，并用周期块 PCR 求解。每个切向频率的块大小为 12。所有返回场仍用原 A64 验收：

- 原始 b 归一化残差 <= 1e-5。
- 由正碰撞裕量计算的相对误差上界 <= 1e-3。
- 与配对原生 TSA16 场的相对差 <= 1e-4。
- 失败与超出最大 100 步的结果全部保留。

验收裕量为 c = min(sigma_t - sigma_s lambda_max(P_sym))；delta=||b-Au||/c，上界为 delta/(||u||-delta)，仅在分母正时有效。相位矩阵使用实际离散角权重。它是当前离散问题的误差检查，不是连续方程误差证明。

## 实现与代价

新增代码 layered_inverse.py，未修改生产算子、已有求解器、默认配置或旧实验回执。

compact4: D_c = M^{-1}K，M=I+(S_+ + S_-)/4，K=3(S_+-S_-)/(4h)。把方程左乘 M 后得到周期块三对角系统。迎风版本使用正负速度分裂。PCR 使用 log2(N) 级消元，初始化约 O(N^2 L^3 log N)，一次作用约 O(N^2 L^2 log N)，因子内存 O(N^2 L^2 log N)。这些是本实现复杂度，不是层状求解的下界。

另用秩 L Woodbury 修复法向 Nyquist 模式，使该单一模式与原 Fourier 符号相符；不除以掠射角速度。

CPU 12 项测试全部通过：小规模 PCR 对 dense solve 相对误差 <= 3.57e-16；两坐标轴、两离散、Nyquist 正向/逆向测试的最大自身方程误差 <= 2.81e-11。CPU 测试不是原离散精度验收。

GPU 初步测试暴露两种不同失败：

- compact4 complex64 的自身方程残差可达 15.42，不能作为准确背景求解器；后续完整求解排除了它。
- compact4 complex128 的自身方程残差约 1.76e-9 到 3.39e-8，但原 Fourier 背景残差仍约 1.69 到 3.74。提高精度没有修复离散错误。
- 迎风 complex64 自身方程残差约 0.00117 到 0.01216，原 Fourier 背景残差约 0.388 到 0.794。它只作为候选方向，不冒充精确逆。
- 迎风单次捕获后 G 约 0.73 ms / 3.54 ms（N128/N256，诊断样本）。这是作用时间，不含 setup、投影、验收或后续 TSA。
- 全 16 例的迎风平均因子初始化为 30.14 / 98.86 ms，捕获另需 8.10 / 18.30 ms；每材料因子分别 302,137,344 / 1,359,249,408 bytes。

初步探针使用 torch.cuda.graph context manager，后续改用与强经典实现一致的私有流直接 capture_begin/end，避免自动 GC/cache flush。保留初版代码 layered_inverse_probe01.py 及其哈希；后续没有改动全局 GC/分配器设置。捕获与 eager 输出差异均通过 <1e-12 检查。

## 全 16 例强对照

每个介质一个 warmup 和三次随机顺序测量，先取介质内中位数，再对物理介质等权平均。所有方向在第一步 TSA16 后注入同一个 augmented FGMRES，保留 Krylov 空间，然后继续 TSA16。原生 TSA16 为决策基线，无注入 augmented 入口用于检查控制流开销。

warm 包含求解、转换、投影、后续迭代和独立验收；Q1 另计每材料的物理算子、验收准备、TSA 因子/捕获与该方法额外 setup。Q1 是进程内单 RHS 成本，不是整进程冷启动，未包括 Python/CUDA 启动和读盘。完整 worker 墙钟另外保存。基线与候选逐介质共享相同公共 setup 账项。

层状 G 的平均 TSA 调用数从 4.5 降至 3.6875 / 3.625。均匀背景与 TSA1 均只有 4.4375，且整体更慢。因此热求解收益有几何归因证据，不只是“随便加一个早期方向”。

配对物理介质 bootstrap（4000 次，复用开发集条件下）中，层状 G 的 warm 时间变化 95% 区间为 N128 [-7.33%, +2.71%]，N256 [-12.19%, -3.75%]。这不是独立泛化确认，且 setup 每材料只测一次，该区间不覆盖 setup 复测方差。

在**假设后续 RHS 的平均收益完全保持**且材料不变的外推下，纯盈亏平衡需要约 36 / 14 个 RHS 共用因子；N256 达到 5% 总成本收益约需 32 个 RHS。当前并没有这种已验证工作负载，因此不能用摊销数字挽救 Q1 失败。N128 目前 warm 收益本身低于 5%，这一外推下不存在 5% 门槛的有限 RHS 数。

## 免费准确 q、Born 与短 GMRES

在 4 个诊断介质（0、4、7、14）和两个网格上，对迎风32与 compact4_64 比较：

- 直接 G。
- 首阶 Born：w=G r，e_B=w-G Vw（两次 G）。
- 短 GMRES：用两次 G 和原 A64 构造两方向物理最小残差修正，所有 A 作用和投影计时。
- 各自作为独立预条件器；以及仅第一步后注入一次、再继续强 TSA16。
- N128 另用既有精确 teacher 在实际第一步前缀构造 q_known=V(u_teacher-x_1)。数据与材料逐项相等检查，teacher 原方程误差 <2e-9；动态前缀与生成 q 的前缀逐位相等。

Oracle 的在线动作仍支付 incident G(r) 和 reconstruction G(r-q_known) 两次 G。精确 q 的取得成本给予免费优惠，单独记录已有 teacher 与前缀取得时间。这里是对该物理 q 目标有利的诊断，不是可部署算法。

全部 48 个“完全替换 TSA16”的配置在 100 步内未通过，共 192 个记录失败（包含 warmup）；其余 352 次注入/基线尝试通过。完整诊断共 544 次记录尝试，不能称为 544 次成功求解。

## 数学反例和学习目标修正

若 G=A_s^{-1} 真正精确，则 e=G(r-q)，q=Ve，满足 (I+VG)q=VGr。学习 q 的理由成立与否，依赖 G 的质量和成本，而不仅是 q 的空间集中性。

使用近似 G_tilde 时，令 D=A_s-G_tilde^{-1}。真实 e 满足

e = G_tilde[r - (V+D)e]。

因此仅提供精确物理 inclusion 源 Ve，仍遗漏 De；De 来自全域离散差异，并不被 inclusion 小支撑控制。真正与该离散解码器闭合的目标是 q_eff=(V+D)e，而不是 q=Ve。定义 q_eff 不代表它便宜、局部、可学习或有经济价值。

对**精确** G，预测误差 delta_q 产生原残差 A G delta_q。因此应检查 ||A G delta_q||/||b|| 及完整求解时间，不能仅以 q 的 L2 误差、支撑占比或尾场能量作为验收代理。

本 compact4 家族还有一个无需网络的反例。取均匀介质 V=0、q=0，法向 Fourier 模式 k=N/2-m，固定整数 m>0：

kappa_c = (3N/2) sin(2 pi m/N) / [1 - 0.5 cos(2 pi m/N)] -> 6 pi m，

而原 Fourier kappa_F = pi N - 2 pi m。compact4 把 Nyquist 附近的高频误认为有限频率。秩 L 的 Nyquist 修复只修 k=N/2，不能修相邻模式。标量输运的相对逆缺陷为

|Omega (kappa_F-kappa_c)| / |sigma + i Omega kappa_c|，

固定非零 Omega、sigma、m 时随 N 线性增长。完整角耦合模型中，相应矩阵缺陷也可能随 N 增长。这解释了为什么“高阶差分+修一个模式”不保证对 Fourier 问题的可接受原残差；它不是所有近似层状方法的下界。

## 下一步边界

当前结论是“局部物理 q + 本 G 解码器”的 scoped NO-GO，以及“几何有用但 setup 未经济化”的概念里程碑。

只在以下有实质变化时重开，不继续盲扫同族参数：

1. **保持 Q1 工作负载**：寻找与原 Fourier 更一致、无需这份逐材料大因子的背景作用，例如独立评估 Fourier 层状算子的可压缩表示。第一关仍是实际 residual/RHS 的原离散缺陷和 setup+action，不先训练。
2. **实际可访问的同材料多 RHS**：另立真实工作负载，冻结源分布与总资源，检验 factor 复用相对批量 TSA16 的完整成本。没有这项工作负载就不外推宣传。
3. **另一种学习对象**：只有解码器闭合与成本门槛通过后，才测试 q_eff 或低维修正方向。用 held-out 材料/角度/网格的原方程验收及完整时间作为目标，同时保留无学习 G、Born、短 GMRES、原生 TSA16 控制；训练预算、teacher 成本、预处理与推理均入账。当前没有足够证据启动该训练。

上述是三个不同表示/工作负载变化，不是本轮已经验证的算法。预留 9626 仍未触碰；本轮结果不具备 production promotion 或发表级泛化结论。
