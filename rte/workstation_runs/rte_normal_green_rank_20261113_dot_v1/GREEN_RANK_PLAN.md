# Fixed normal-space Green representation discriminator

## Why this changes the research object
The original research goal is an affordable material-conditioned nonlocal inverse action, not a winning second-injection schedule. Fixed-second-injection, expanded shell, and cheap B8 variations are closed. Existing dense/full-angular background inverse factors preserve physics but incur significant construction/application costs.

Test a distinct representation: for each fixed tangent Fourier mode, retain all12 angles but compress separated normal-physical interaction blocks of A0(k)^{-1}. A continuous local first-order system motivates a finite interface state; it does NOT prove rank12 for the actual dense Fourier discretization, rounded geometry or stored Nyquist. Source-independent measurements must decide.

Independent source audit distinguishes this from old hierarchy: hierarchical_response.py and audit_parity_response_blocks.py concern a 2D periodic quadtree of six even-parity angular channels in a general heterogeneous parity-Schur inverse. Existing HSS denotes Hermitian/skew-Hermitian splitting, not this hierarchical matrix. The old inverse error near9.3e-4 with physical residual defect about0.206 is a specific warning: SVD energy alone is insufficient.

## Fixed objects and representation
Four objects only: N128/k0, N128/k8, N256/k0, N256/k8. Use the existing medium generator and actual extracted min/gather normal background; N128 must equal sealed E/K background. N256 is the corresponding sampled existing layer-profile family, not a claim to solve a new heterogeneous K problem. No physical source/teacher or reserved data is read.

Actual stored12 angles, full g=.65 scattering matrix, normal/tangent frequencies and Nyquist retained. No idealized angular/periodic symmetry or +/-k reuse. Dense matrices independently bridge both the exact mode action and full original-A0 embedding.

Space-major normal-cell ordering, each cell carrying all12 angles. Fixed rank12 far blocks, fixed8-cell dense leaves. A block is far only if periodic interval separation >= maximum interval diameter; touching and periodic-neighbor fields are subdivided and ultimately kept dense. No rank, leaf-size, admissibility or tolerance search.

Construct the dense original inverse solely as a paid diagnostic reference. Build the fixed hierarchy by SVD, verify disjoint block coverage and hierarchical-vs-assembled action. Measure BOTH relative inverse error and full assembled I-A0 B Frobenius/max-column defects. Additionally report separated and periodic-adjacent quarter-block spectra, fixed-rank errors and original-A0-weighted errors. Rank curves at standard diagnostic accuracies are descriptive, not deployed rank selection.
