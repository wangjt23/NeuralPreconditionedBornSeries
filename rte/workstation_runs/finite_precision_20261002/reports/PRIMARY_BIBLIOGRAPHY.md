# Verified primary references for the finite-precision analysis

Checked 2026-10-02 through official publisher, author or vendor sources. These references support distinctions and model structure; none certifies the project's actual cuFFT kernels or licenses changing the frozen failed cap. The formulas in THEORY.md are explicitly derived for the inspected source.

1. Yousef Saad, **A Flexible Inner-Outer Preconditioned GMRES Algorithm**, SIAM Journal on Scientific Computing14(2),461–469,1993. [Publisher/DOI](https://epubs.siam.org/doi/10.1137/0914028). Flexible right preconditioning stores actual preconditioned directions and images rather than assuming a single fixed polynomial preconditioner. This does not imply nonlinear outer systems are covered by the linear residual identity or that finite-precision/restarted trajectories dominate another solver.

2. Valeria Simoncini and Daniel B. Szyld, **Theory of Inexact Krylov Subspace Methods and Applications to Scientific Computing**, SIAM Journal on Scientific Computing25(2),454–477,2003. [Publisher/DOI](https://epubs.siam.org/doi/10.1137/S1064827502406415). An explicit inexact matrix-vector model separates the mathematical residual from the projected residual and weights errors through computed coefficients. Its analysis assumes exact surrounding arithmetic; the RTE note therefore adds orthogonalization, source-residual and field-construction defects explicitly. An auxiliary preconditioner action error is not automatically an outer matvec error.

3. James C. Schatzman, **Accuracy of the Discrete Fourier Transform and the Fast Fourier Transform**, SIAM Journal on Scientific Computing17(5),1150–1166,1996. [Publisher/DOI](https://epubs.siam.org/doi/10.1137/S1064827593247023). FFT accuracy depends on the chosen algorithm and software/twiddle accuracy. Its analysis motivates separating a transform's forward contract from spectral differentiation amplification; it is not a validated worst-case constant for proprietary cuFFT12.4 kernels.

4. NVIDIA, **cuFFT12.4.1 API Reference**, §2.13 Accuracy and Performance. [Version-pinned official documentation](https://docs.nvidia.com/cuda/archive/12.4.1/cufft/index.html#accuracy-and-performance). Documents Cooley–Tukey building blocks, qualitative logarithmic error growth, different Bluestein behavior, and reproducibility when plan inputs, cuFFT version and GPU model stay fixed. It supplies no numeric norm-specific constant sufficient to instantiate εF/εI. CUDA12.4 reported by Torch is not independently proof of the exact bundled library/plan configuration; no new runtime query was made.

5. NVIDIA, **Floating Point and IEEE754**, CUDA12.4.1. [Official documentation](https://docs.nvidia.com/cuda/archive/12.4.1/floating-point/index.html). Explains round-to-nearest behavior, operation ordering and FMA's single rounding versus separate multiply/add. This supports conditional elementary-operation models; it is not a bound on a library FFT or uninspected tensor contraction.

6. PyTorch, **Numerical accuracy**, version2.5.1. [Official version-pinned source](https://raw.githubusercontent.com/pytorch/pytorch/v2.5.1/docs/source/notes/numerical_accuracy.rst). Qualifies rounding/order, backend/batched differences, nonfinite linalg behavior and possible reduced-precision paths. The deployed runner's effective flags and kernel contract must be established separately; defaults or storage dtype are insufficient evidence.

7. PyTorch, **torch.fft API documentation source**, version2.5.1. [Official source](https://github.com/pytorch/pytorch/blob/v2.5.1/torch/fft/__init__.py). Confirms `fftn` backward mode is unnormalized and `ifftn` backward mode applies1/n. A unitary DFT can therefore be used analytically while respecting original operation/normalization semantics.

8. A. Bouras and V. Frayssé, **Inexact Matrix-Vector Products in Krylov Methods for Solving Linear Systems: A Relaxation Strategy**, SIAM Journal on Matrix Analysis and Applications26(3),660–678,2005. [Publisher/DOI](https://epubs.siam.org/doi/10.1137/S0895479801384743). Provides the relevant monitored inexact-product predecessor. Its residual-related strategy does not derive the project's auxiliary FP32 homogeneity cap. The independent ARNOLDI_REVIEW.md checks its scope alongside the author-uploaded Simoncini–Szyld full paper.

No secondary review, search-result claim or informal forum post is used as a numerical guarantee. SIAM publisher pages confirm paper identity and scope; any claim requiring an unavailable implementation-specific full error contract remains conditional rather than being supplied from memory or empirical fitting.
