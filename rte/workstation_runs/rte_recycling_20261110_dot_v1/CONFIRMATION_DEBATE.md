# Frozen follow-up gate: confirm the same-instance result before expanding scope

## Debate round 1: competing next actions
A. Repeated, counterbalanced same-instance CPU timing. The current14% batch advantage comes from one method-ordered pass. A cold/warm or temporal-load bias could change the conclusion even if the mathematical mechanism is real. This is the cheapest unresolved decision risk.
B. Independent material variation. This would test whether coupling structure transfers, but a new material cannot repair uncertainty in the original speed claim. Define the perturbation distribution before inspecting results; do not turn a selected easy material into confirmation.
C. A6000 translation. CPU and GPU setup/application ratios can be very different, but GB owns the GPU now, and moving before fixing the comparator would conflate hardware and algorithm effects.

Select A. No conforming repeated timing already exists: the first recycling stage was a single recorded warmup-style mechanism pass; both background stages used one pass. Therefore this is not redundant repetition.
