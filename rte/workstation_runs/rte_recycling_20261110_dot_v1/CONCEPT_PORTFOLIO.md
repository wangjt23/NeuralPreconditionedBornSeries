## Round 1: three genuinely different architectures
1. **Paid online Krylov recycling (selected).** Persist U,C with A U=C and C^T C=I in real-stacked arithmetic. Initial x=U C^T b, then project each candidate z to z-U C^T A z. This removes prior image-space work and changes when already-paid information is discarded. It does not require a globally low-dimensional solution manifold. Known classical family: GCRO/GCRO-DR and recycled FGMRES; no novelty claim.
2. **Exact normal Fourier background action (deferred).** Diagonalize tangent frequencies, factor exact dense normal-angle blocks, repair only actual nonlayered inclusion. This changes the discrete background operator, escaping compact-G streaming mismatch rather than fitting coefficients. The N128,L12 blocks are dimension1536 for each128 tangent frequency, so setup/storage are substantial; count actual multi-RHS break-even. Cheapest next proof would be one tangent-frequency exact action and discrepancy spectrum, not a full production factor bank.
3. **Residual-linear material-local ROM (deferred).** Build a per-medium or nearby-medium response dictionary using paid representative residuals; construct small A-projected inverse and preserve linearity in RHS. This changes the cross-material/global POD premise. It still needs useful source coverage and paid setup. Strong null: online recycling obtains equivalent directions from actual solves without extra probes.
