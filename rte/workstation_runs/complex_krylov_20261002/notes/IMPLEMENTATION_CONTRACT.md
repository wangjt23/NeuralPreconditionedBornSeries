# Complex outer-Krylov companion contract

`complex_augmented_fgmres.py` is isolated new code. It imports only Python `math` and existing `torch`; original and previously frozen files are unchanged. The call signature matches `rte.augmented_fgmres.augmented_fgmres`, adding optional `capture_injection`. Defaults remain source-relative tolerance `1e-5`, restart `25`, maximum `100` accepted directions and one injection after `4` global classical calls.

The caller supplies the original FP64 physical action/RHS, original N128 balanced initial field and full-reference proposal, and the already prepared strongest classical preconditioner. The N256 zero-start call supplies no injection. Input conversion to FP32 and owned128 return belong to that unchanged preconditioner wrapper. Complex-linearity/admissibility checks of the actual physical action and rounded preconditioner are external entry gates; the solver does not silently add probes or claim exact linearity of a rounded action.

The new outer arithmetic uses conjugate MGS and complex coefficients. Every tiny `(j+2) × (j+1)` least-squares problem uses a complex SVD, with `rcond=max(matrix.shape)*eps(rhs.real.dtype)` and an explicit pseudoinverse. The original absolute Arnoldi cutoff `1e-14` and injection image-independence threshold `1e-12*||H z||` are retained. Rank loss or nonconverged Arnoldi breakdown stops explicitly after checking the last finite candidate; no zero/tiny frontier is normalized. A useful injected image inside `span(V)` but outside `span(AZ)` is solved before handling breakdown. Rejection consumes the sole optional attempt while preserving the classical frontier, accepted H/Z and iteration budget.

Status retains the original counters and `true_residual`, `failed`, `trace`. Additional `rank_deficient_steps`, `breakdowns`, `breakdown_reason`, `cycles` and scalar `injection_stages` expose exceptional paths. `failed` depends on a fresh original-RHS physical residual and finite field. As in the original solver, iterative corrections use `b=rhs-H(initial)` and `b-H(correction)`; the final physical check evaluates `rhs-H(initial+correction)` directly.

Prefix capture retains the original keys and adds `directions` (actual Z), `images` (unprojected actual HZ), `frontier`, `arnoldi_basis`, `hessenberg`, `cycle_start_solution` and `cycle_start_residual`. After a restart, Z/HZ refer to the current cycle only. `image_basis` is complex-orthonormal in nominal Hermitian geometry and is `None` on rank loss/breakdown; raw Z/HZ remain available. Diagnostic callbacks own serialization and their costs. The optional injection callback follows the existing instrumented callback payload, with complex columns and fields.

This changes both coefficient freedom and numerical rank handling relative to the frozen real control. All SVD/reductions/copies/guards and physical checks must be charged. It is therefore a matched physical-recipe discriminator with disclosed safeguard differences, not pure coefficient-only runtime attribution. The complex-span inclusion theorem concerns exact fixed complex-linear operators or one frozen shared Z/HZ basis; it supplies no runtime, restarted-trajectory or rounded-preconditioner dominance guarantee.

CPU tests use deterministic tiny dense fields, direct dense solves, the unchanged original real authority and an independent rank-aware complex LS driver. The local compact snapshot isolates its exact conversion functions only for importing the real authority. Flat staging on FWI imports the real repository normally through `PYTHONPATH=.`; no source shadow or package addition is installed there. Substantive FWI execution remains controlled by the parent protocol.
